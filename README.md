# Friendly Eats

Rede social de comida e varejo de restaurantes: culinárias, tipos de comida, estabelecimentos, preço, local e
avaliações de 0 a 5 estrelas.

Mesma base técnica do Orange Social (Spring Boot 4.1 / Java 21+, PostgreSQL + PostGIS, Valkey, Cassandra, API S3,
LGPD e documentação por requisito com diagramas Mermaid). O código chega por pull requests a partir desta branch.
